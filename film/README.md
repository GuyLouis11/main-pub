# Guy Wonders Why: "The Boy Who Froze Hot Water" · chapters 1–6

This is the full film after the opening. The opening lives separately in `../hot-water-opening/`, so the two can be merged without overwriting each other.

| File | What |
|---|---|
| `TIMELINE.md` | **Narration-to-scene map for the whole film** (generated): film time, VO line, picture, Flow file and usable in/out, references, transition out |
| `VO_HANDOFF.md` | All 43 chapter narration lines with filenames and paths (plus the opening's 8) |
| `FLOW_REVIEW_BATCH2.md` | Frame, audio and defect review of F04/F07/F10/F13 and how each is used |
| `QA.md` | Checks actually performed, what is final vs placeholder |
| `renders/film_v1_review_small.mp4` | Assembled review cut: opening + 6 chapters, SCRATCH VO subtitles, **silent VO** |

## Layout
```
shared/            design system (film.css), VO-driven timing engine (film.js), fonts, GSAP, textures
chN/index.html     one HyperFrames project per chapter (timing block + scenes + GSAP timeline)
chN/assets/vo/     C#_##.wav   ← SILENT placeholders until ElevenLabs takes arrive
chN/assets/flow/   real Flow clips + hold stills
chN/assets/audio/  music.wav / sfx.wav (generated by tools/chapter_audio.py)
tools/             retime_chapters.py · chapter_audio.py · audiokit.py · sync_shared.py · make_placeholders.py · render_all.sh
```

## How timing works
Each chapter's `<script id="timing">` lists scenes with their VO lines, minimum lengths and crossfade overlaps. `shared/film.js` and `tools/retime_chapters.py` use the **same rule**:
- a scene lasts as long as its narration plus lead and tail room, or its visual minimum if that's longer;
- key animation beats are keyed to VO starts or proportional points (`V()`, `P()`).

Drop in real takes, run the retime, and every scene, clip slot, score cue and the TIMELINE follow. Flow clips stay inside their reviewed usable windows.

## Commands
```bash
npm install && npx hyperframes browser ensure
python3 tools/sync_shared.py          # after editing shared/
python3 tools/retime_chapters.py      # after VO changes (writes timings + TIMELINE.md)
python3 tools/chapter_audio.py        # score + SFX on the new layout (ducks under real VO)
npx hyperframes lint ch3 && npx hyperframes check ch3
bash tools/render_all.sh              # review cut (scratch subtitles); CLEAN=1 for the final picture
```
