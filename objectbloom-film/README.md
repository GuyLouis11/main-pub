# object bloom. — showreel film

A 40-second film for objectbloom.com, made entirely in code: one desk by a window, one day of light, one object.

1. **Dawn.** A pencil sketch draws itself, and a lens rises out of the page.
2. **Morning.** The lens comes apart into an exploded view with labelled parts.
3. **Midday.** The camera looks through the glass into a live dashboard on the laptop.
4. **Dusk.** The chart's bars lift off the screen and stand up as towers, and a model city rises around them as the lamp comes on.
5. **Night.** The iris opens like a flower, and the wordmark appears.

Every model, material, light, camera move, interface frame, drawing, title and note of music is generated by the
scripts here. No downloaded 3D models, textures, stock footage or stock audio.

## Pieces

| Path | What |
|---|---|
| `film/lib.py` | geometry, materials and keyframe helpers (Blender 5.3 `bpy`, Cycles) |
| `film/lens.py` | the hero lens: 11 assemblies, 6 glass elements, a 9-blade iris, engraved name ring |
| `film/scene.py` | the room, desk, sketchbook, laptop, lamp, props, the chart card that becomes a city |
| `film/anim.py` | the 960-frame timeline: light through the day, every move, cameras, focus |
| `render.py` | renders frames; `--anchors` exports label positions for the titles |
| `ui/index.html`, `ui/render.mjs` | the dashboard, rendered frame by frame with headless Chromium onto the laptop screen |
| `tools/make_art.py` | the self-drawing sketch and the framed print |
| `audio/score.py` | the score (felt piano, strings, plucks, bells) and sound design, mastered to -14 LUFS |
| `post/overlays.py`, `post/assemble.sh` | titles and callouts; final composite and encodes |
| `pod/` | RunPod render farm: a hub pod plus any number of single-GPU workers pulling 12-frame chunks |

## Rebuild

```bash
npm i && node ui/render.mjs && python3 tools/link_ui.py     # dashboard frames
python3.13 tools/make_art.py                                # sketch + print
python3.13 audio/score.py                                   # audio/mix.wav
python3.13 render.py -- --anchors post/anchors.json         # label positions
python3 pod/pod.py create 1 && pod/pack.sh                  # hub pod (RunPod key via env RUNPOD_API_KEY)
python3 pod/pod.py worker w1 final 3840x2160 160            # add workers; the hub runs pod/worker.sh too
bash post/assemble.sh /workspace/o/final objectbloom_showreel   # on the hub
```

A 4K frame takes 8–22 s on one RTX 4090 (Cycles, 160 adaptive samples, OptiX denoise).
